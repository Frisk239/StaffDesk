# 未核积压靠周期再见与整理兜底；未核被纠正是丢弃，不写禁写

任务末批量晋升卡被拒绝后，未核不能变成无限积压（审计 C3），但也不值得为它加第六套确认机制（待确认页第三段，D7 已批评确认机制过多）。StaffDesk 两个自然出口：其一，任务结束时批量卡覆盖的是该对象当时的全部未核，积压在下一个任务周期自然再见面；其二，整理提议（0017）新增「丢弃未核」类型——对滞留多日的未核主张提议丢弃，人确认才删。连带裁决 refit §2 挂起项：未核主张被纠正时不写全局禁写、直接丢弃——禁写只保护已出过站的定论（0034 的补偿原子性同理只锚定已生效效果），没出过站的东西不值得永久拦截同句，否则纠正一条未核垃圾反而留下永久误伤。
