# 四组工具；说明书开场注入，不是记忆

参谋台循环不只是搜网页。Codex 把 AGENTS.md（人写的规矩）和 memories（模型生成）拆开；Claude Code 把 CLAUDE.md 和 MEMORY.md 拆开；GBrain 把世界页和 agent memory 拆开；Mem0 管偏好不管档案。StaffDesk harness 工具分四组：眼睛（适配层，仅调研）、账本（对象/来源/主张/纠正/晋升）、记忆（只要关于使用者）、办事（任务/简报/回放）。开场注入说明书和当前对象摘要，不靠模型自己编流程。对话默认只读；「记下来 / 这句不对」才打写入。世界事实走账本，不走记忆。不暴露 Graphiti/Mem0 当功能名，不给无约束 shell。
