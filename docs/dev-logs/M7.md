# M7 桌面形态

状态：自测完成。安装包未在本机打完验收（electron-builder 配置已在 `app/electron-builder.yml`）。

## 做了什么

- 点叉进托盘，首次提示「右键托盘可退出」；单击托盘唤起。
- 首启向导五步，可跳过；跳过后图标轨有「继续设置」。
- API Key 进系统密钥库（safeStorage），不进大脑文件，导出 zip 不含密钥。
- 设置 → 通用 → 导出大脑。
- 雷达错过的周期只补最新一次，回放标「迟跑」。

## 怎么点

第一次打开会看到向导。密钥填在设置里，重启后仍在，导出的 zip 里搜不到 Key。关窗口会缩到托盘。
