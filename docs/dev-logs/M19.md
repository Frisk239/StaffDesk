# M19 — task entries and closeout hardening

## Scope

把任务层三个缺失入口补成可见用户路径，同时偿还主进程侧快赢债。持久化拆墙与 eval 金标升级排 M20；勘察确认 IPC fail-open 默认值已在 `5a71813` 修复，本刀不再重复。

## Changes

- 调研按钮档位化：对象页顶栏调研主按钮语义不变（点击=快搜），旁加下拉菜单 快搜 / 深挖 / 再搜一轮。「再搜一轮」仅当该对象存在可作上轮的非雷达任务时可用；选中后按上轮任务的档位与 query 创建带上轮语境的新任务（走 `ResearchRunOptions.kind/parentTaskId/query`，与雷达子任务同一路径，不带 dueAt/missedRuns 雷达语义）。
- `task:startResearch` 契约扩展为 `{objectId, gear?, kind?, fromTaskId?}`；ipc.ts 新增纯函数 `researchOptionsFor` 做载荷→引擎 options 映射，上轮任务不存在时回落普通调研。
- 任务列表页：图标轨新增「任务」入口；`TasksView` 按 createdAt 倒序列出全部任务（对象、种类、状态徽章含停止原因、档位、query），行内「打开回放」跳 `SET_VIEW replay`；`ReplayView` 零改动复用，回放从此可达任意历史任务。
- `chat:send` 失败兜底：`CHAT_USER_ONLY` 落账后立即广播（用户消息不再等整轮结束才可见）；模型段整段 try/catch，失败时脱敏 TOAST（0030：如实告知、不编造）+ 广播 + invoke 正常 resolve，渲染端不再悬挂 rejection。
- 删除 `chat:delta` 死发送线与 `SessionDeps.onDelta` 透传（全仓无监听）；保留 CHAT_APPEND_DESK 不落 turn 的现状（渲染端打字机动画契约）。
- IPC 通道单源：`HANDLED_CHANNELS` 常量表约束注册侧类型并驱动 `unregisterIpc`，补「卸载后清零、集合相等」防漂移测试。
- 主进程调试输出清理：better-sqlite3 冒烟块保留快失败、去 console（no-useless-catch 约束下改为带原因重抛）；brain file / 雷达补跑日志删除；runtimeSecurity 安全告警保留。
- 新增 `tests/main/ipc.test.ts`：`vi.mock('electron')` 假 ipcMain 的行为单测（snapshot / dispatch 往返 / ingest:text / chat 写意图不触模型 / chat 失败兜底 / 通道单源 / researchOptionsFor 三态），ipc.ts 从此有行为护栏。
- 两处英文 describe/it 译中（layout / extraction-job）。
- e2e 新增 `task-entries.spec.ts` 三用例：任务列表与打开回放、档位菜单参数映射（contextBridge 暴露对象在页面上下文只读、页面内 spy 不可行，改为主进程侧 `ipcMain` 桩验证 preload 参数映射，且不触网络）、再搜一轮禁用态。
