# 谓词表编辑的级联纪律

谓词表是受控表（0025），是冲突判定、抽取映射与简报槽块的公共键。M25 之前它只能加不能改——加错的槽、起错的名永久留在表里。编辑开放后必须钉死级联纪律，否则一次改名会让旧名主张从对象页与简报里消失、让禁写静默失效。

编辑是人手设置动作：`UPDATE_SLOT`（改名 / 单值↔多值 / 场景适用标记）与 `REMOVE_SLOT`（删除）直接改账本，**不进撤销卡**——operations 日志每行留痕，改名可再改回、删除可重加（对齐关系/归档的既定口径，批量改名的补偿卡会过长，不做）。kind 不可改：换种类等于跨分区搬家，抽取按对象种类走映射会乱。

**改名级联三处**：slotDefs 该行；该槽全部主张的 `predicate` 同步重写（投影、冲突派生、简报槽块都以槽名为键，不同步则旧名主张从对象页消失、掉进简报背景块）；**禁写记忆的结构化谓词列（0054 的 `bannedPredicate`）同步重写**——不同步则禁写的槽匹配静默失效。指向旧名的挂起整理/编目提议一并撤下，不留确认必报错的死卡。

**删除级联**：该槽的成立主张降为「未编目」——自动获得抽取映射不上的全套既有语义（不建冲突 0037、简报降级「材料提到·不作定论」、整理出编目卡）；已关窗主张保留旧名作历史。确认对话框须先展示「成立主张 N 条（将降为未编目）、涉及对象 M 个」。

**守卫**：新名非空、非「未编目」、(名, 种类) 不撞库内 UNIQUE；被内置场景简报说明（BRIEF_SPECS）引用的谓词禁改禁删——简报块以谓词名为键，M26 把简报说明数据化之前这层保护不动。arity 多值→单值可能瞬间派生新冲突：这是 0029 的合法派生，切换前告知将产生的冲突处数，由人按关窗纪律消解，系统不自动关任何主张。

**种子防复活**：presets 种子门从「表空才插」改为首启标记（app_meta）——用户清空谓词表后重启，不得被默认槽重新插回；既有已种子的库补写标记，不重复播种。
