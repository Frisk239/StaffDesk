# 抽取与 dream 是主会话背后的专责循环；正确性靠分仓、立刻禁写、候选不自动升

Claude Code 与 Codex 的共同形态：主会话继续办事；另开抽取循环从本会话写记忆；再另开 dream 做合并去重。Claude 的 extractMemories / autoDream 是受限工具的后台子 agent，dream 加锁、只许写记忆目录、失败回滚；Codex Phase 1 在后台按会话结构化抽取并去密钥，Phase 2 拿全局锁再跑 consolidation 子 agent（无网、只许本地写、禁止再委派）。HaluMem 表明幻觉主要发生在抽取和更新，再污染问答；Mem0 生产审计显示把已召回记忆再抽一遍会放大编造。Claude 用单文件 MEMORY.md 并发改写会丢行，是反面教材。StaffDesk：主会话不顺手抽。明确「记下来」和纠正立刻写耐久记忆，禁写当场生效。会话结束的抽取循环只扫本会话原文，产出候选，不抽闲聊、不抽世界事实、不把开场召回的记忆当新事实。候选不自动升全局或对象。dream 只整理记忆、加锁、一次一条；主张整理仍是「整理」且须人确认。共享记忆只追加行，不用单文件改写。dream 不准删禁写、不准改账本；吃不准的合并保持两条或给人看，不学 Claude dream 直接删「矛盾」笔记。并行会话各写会话层，共享层只追加；评测已含纠正复发。
