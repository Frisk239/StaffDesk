# M2 对话真连

状态：自测完成。可与 M3/M4 一并验收。

## 做了什么

- 自写 chat-completions 客户端（fetch，支持流式、JSON mode、429/5xx 最多 3 次重试）。密钥打日志时掩码。
- 设置自检 1 级连通（GET /models）、2 级能力探测（微型 JSON `{"ping":true}`）。第 3 级资格认证留给 M6。
- 主会话：说明书开场 + FTS/片段召回 + 只读工具组（召回主张 / 读来源片段 / 列冲突 / 读简报 / 查空槽）+ 带 `[ref:ID]` 的引用。闲聊不写主张。
- 「记下来 / 这句不对 / 删除」仍走本地纪律，不交给模型写账本。
- FTS 选型记入 ADR 0042：trigram + 短中文查询退回原文包含。

## 怎么点

设置里填兼容端点的 Key，点插头做自检。打开对象，普通提问走真连（没 Key 时仍用本地脚本回答，不编新主张）。引用只能点回已有主张。

## 测试

mock fetch：成功、重试、掩码、连通失败、能力探测 JSON。会话循环：伪造 ID 不会进引用；CHAT_SEND 后主张数不变。
