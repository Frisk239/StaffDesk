# 简报挂在对象和任务下，是出站快照不是第四种对象

把简报做成和对象平级的文档柜，会变成第二套 wiki，和主张账本抢真值。业内匹配：NotebookLM 的 Briefing Doc 从属于笔记本，在 Studio 里生成，不是另一种笔记本；GBrain 的 briefing 从大脑现查现编、带引用，默认只读、不改页；CRM 的报价/提案挂在这一单（Opportunity）上，Account 仍是活档案，报价是可留历史的版本。StaffDesk：从对象上开任务出简报；全局最多做「最近简报」入口，点进去仍回对象。简报是当时能出站内容的快照。默认不把简报当新来源（派生）。对象页继续按主张生长。
