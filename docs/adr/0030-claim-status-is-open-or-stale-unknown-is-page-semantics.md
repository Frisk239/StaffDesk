# 主张状态收敛为成立/过时；未知只是页面语义；部分成立 v1 删除；未核是与状态正交的标志

「未知」身兼两职：既是主张状态枚举的一员，又指「该槽没有主张」的空格子。空格子根本不是主张，而「一条主张 status=未知」没有任何来源场景能产出它——检索失败和材料不足发生在槽层面，不在命题层面。「部分成立」四态里零判定规则、零转换、原型零使用，是只有入口没有出口的状态。StaffDesk：主张状态收敛为成立/过时两种，加上关闭原因（世界已变/从未成立/来源删除/对象误建，见 0031/0032）完整描述一条主张的世界真值史；未知只作为页面与简报的占位语义存在——槽内无主张、检索失败、材料不足时格子空着并如实说明，它永远不是账本字段的值，「未知遵守」评测测的是出站纪律（该空的格子有没有被编造填满），不是状态转换。部分成立从 v1 删除；将来若出现「原文带限定词（部分时期、某些业务线）」的真实需求，以抽取时的限定标记引入并映射进句子正文，不复活整状态。未核是与状态正交的核对轴标志：状态回答「这条命题在世界里真不真」，未核回答「这句是自动写入还没经人核对」；两轴独立组合（成立·未核 / 成立·已晋升 / 过时·未核 / 过时·已晋升）都合法且各有含义，审计卡并排展示两轴，晋升只翻核对轴、不动状态轴。抽取写入的新主张一律 status=成立 + 未核，由人通过纠正或整理关窗。
