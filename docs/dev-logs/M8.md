# M8 真实模型主链可信化

状态：完成（2026-08-30 审计收口）。Phase 2 路线见 `docs/implementation-plan-phase-2.md`。

## 做了什么

- 主张抽取 module 不再只返回空数组或主张数组，改为显式终态：`success`、`unconfigured`、`invalid-output`、`failed`，并带候选数、拒绝数和脱敏短原因。
- 结构化响应兼容纯 JSON、Markdown JSON 围栏和带前后说明的 JSON 对象；Zod 结构不合格不写账本。
- 抽取提示明确传入绑定对象、按对象种类分组的受控槽名、逐字 span 与完整命题要求。修复了把 `组织:槽名` 误导成 predicate 的格式问题。
- chat-completions 统一加 60 秒硬超时；一级连通检查加 15 秒超时。超时和网络错误会结束抽取作业，不再永久停在“抽取中”。
- 来源状态区分抽取中、失败、未配置、无可核对主张、已有主张，并提供重试入口。结果卡不再把所有空结果写成“未配置模型”。
- 资格认证复用同一抽取 interface；技术失败显示认证未完成，只有合法抽取结果才计算质量分数。

## 2026-08-30 审计收口

- 抽取主张 ID 改为不透明 UUID，幂等键继续用于去重，重抽不再撞主键。
- 一次丢弃多条未核主张会记录整批快照，重启后仍可原子恢复。
- 来源支持独立解绑当前对象与删除来源；删除来源会展示绑定/主张影响数，关闭仍成立的相关主张，保留已过时主张的原关闭原因。
- 删除来源不做结果卡一键撤销，但操作日志保留来源正文、绑定和主张快照；设置页提供显式“恢复来源”入口。
- `extract:run` 与渲染层调度都保证失败终态和 `finally` 释放；非 success 抽取结果即使误带 claims 也不会写入账本。
- 窄窗首次打开会立即 fit：900px 首屏保留可用右栏，来源/档案入口可达。
- 模型端点、Key、模型列表、启用状态或实际供应商/模型选择变更后，认证状态回落为“未认证”，包含隐式选模路径。
- 抽取完成落账会按当前账本再次核验幂等键，解绑后快速重绑产生的并发结果也不会重复写入同义主张。
- 跳过首启向导只关闭本次向导，不再冒充完成；左侧保留独立的“继续设置”入口。

## 真实端点隔离验收

使用产品全局配置中的真实端点和临时 `brain.db`，材料为内置隔离场景文本：

1. 创建临时工作区与组织对象。
2. 写入来源并绑定。
3. 真实模型抽出 2 条未核主张，分别进入 `在招岗位` 与 `后端主栈`，span 均能逐字指回原文。
4. 生成 5 块简报，2 条事实均带主张引用。
5. 三级认证结果：连通通过、能力通过、召回 100%、忠实 100%、未知遵守 100%、编造率 0%。
6. 退出后删除临时数据库；用户业务库没有写入隔离样本。

## 已知边界

- 当前单次抽取只读取来源前 8000 字符；长材料分块属于 M9。
- 手给 URL 仍只保存 URL，PDF 仍是待解析占位；真实进料 module 属于 M9。
- 认证结果尚未按配置指纹持久化；当前会话内配置变更会立即失效，持久化指纹属于 M11。
- 来源账本持久化与恢复操作日志仍是两个事务；极端崩溃窗口下的原子性加固属于后续存储债务。
- 资格认证的简报忠实度仍以确定性引用检查为主，逐句 span 支持度评测留待 M11。
- 第一版仍只支持 OpenAI-compatible Chat Completions。
