# 任务运行控制先落账；停止是运行时信号，回放读任务审计

M10 已让调研和雷达能真实跑起来，但实现是跑完整轮后一次性把任务、审计和来源写回账本；这会让对象页在长调研期间看不到「进行中」，也无法执行 0007/0018/0036 里承诺的「能停、能看、能回放」。如果把运行态只做成 renderer loading，又会产生另一种假象：界面说在跑，账本里没有任务，刷新或重开后过程不可审计。StaffDesk：调研/再搜一轮启动时先写一条 `进行中` 任务和初始审计；后续搜索、打开、触顶、失败、停止都追加到 `task_audit`，完成时只更新同一任务为 `已完成` 或 `已停止`。主进程 IPC 可以持有当前进程内的停止控制器，但这只是运行时信号，不进大脑文件；真正留下来的事实只有任务状态、停止原因和审计行。用户主动停止不新增「取消」态，按 0036 落为 `已停止 · 手动`；触顶仍可带已打开来源入库，失败/停止不得编来源或负事实。回放只读 `tasks` 与 `task_audit`，不读运行时控制器。
