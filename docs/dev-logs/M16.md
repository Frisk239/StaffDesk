# M16 — task-scoped claim promotion flow

## Scope

补齐 0016 在 M15 任务层之后的真实入口：调研/再搜一轮任务结束后，等本任务写入的调研来源全部完成抽取，再对这些来源产生的 `成立 + 未核` 主张生成一次批量决策。

## Changes

- 新增 `@shared/taskClaims`，统一判断调研来源归属、任务来源抽取是否终态、本任务仍有哪些未核主张。
- 调研来源 `origin` 增加 `taskId`；旧数据仍兼容 `src-res-{taskId}-{index}` 规则。
- `EXTRACT_DONE` 在抽取终态后检查任务来源集合，只有同任务全部来源完成后才入队 `批量晋升` takeover。
- 批量晋升只作用于本任务来源下仍为 `成立 + 未核` 的主张；不包含同对象手给来源或其他任务来源。
- 批量卡按钮改为“全部晋升 / 全部保持”，并在卡上说明晋升不会自动消解冲突。
- 回放页在存在待处理任务批量决策时提示返回对象页处理；确认机制仍只在对象页 takeover。
- 补 ADR 0050，明确任务末未核决策按任务来源聚合，不按对象全量聚合。
