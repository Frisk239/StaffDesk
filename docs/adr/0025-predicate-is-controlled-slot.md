# 谓词是受控槽；未编目不自动判冲突；用户看见句子

冲突、整理合并、抽取幂等、冲突检出评测都挂在「同一谓词」上。Wikidata 用受控属性，冲突可算、复跑可比；Graphiti 用自由文本边名加 LLM 消歧，什么都能抽，但「同一谓词」会跟着模型漂。StaffDesk 要可核对的账本和可回归的评测，不能把判定键交给自由短语。用户看见的仍是完整句子，不是三元组。StaffDesk：谓词是人维护的受控槽；抽取必须映射到表内。映射不上记未编目：可进账本、默认可未核，不自动建冲突，不当简报单边定论；整理提议并入某槽、加新槽或丢掉。幂等键为（来源片段, 对象, 谓词槽）。开题先一小份表（任职于、在招岗位、使用技术、办公地点、融资轮次等），缺了由人加，模型不准自己开槽当判定键。槽表按对象种类分区、每槽带单值/多值声明与可选场景适用标记，谓词表管理界面在设置页，见 0033 与 0029。
