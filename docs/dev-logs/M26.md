# M26 — scenario templates: the four-piece set as data

## Scope

场景四件套数据化（ADR 0058 先行）：场景从五值枚举升为数据行（scenario_templates 表），说明书与简报说明走 state（双源收口），自定义模板 CRUD，建对象引导按场景差异化；M25 的谓词保护解除改级联改写。范围裁决：AI 提议起草场景顺延后刀（先有 CRUD 地基）。叠加态：基于 PR #19（M25）未合分支。

## Changes

### 数据层

- **schema v8**（首个重建表门次，单事务）：重建 workspaces 去掉 scenario 枚举 CHECK（new→copy→drop→rename）；`DROP TABLE scenario_brief_specs`（死表退役）；`scenario_templates` 建表（name 主键 / builtin / hint / playbook / brief_spec JSON）。**三处同 commit 同步**：SCHEMA_SQL、REQUIRED_TABLES（删死表加新表——漏一处备份恢复全线炸）、v8 门次。
- **种子（新键 `scenario_templates_seeded`）**：与旧 `presets_seeded` 完全独立（既有库全是旧键 '1'，复用会永远种不上）；种内置四模板 + 「自定义」空白基线（全 builtin，内容 ← BRIEF_SPECS/SCENARIO_HINTS/DEFAULT_PLAYBOOK 常量，常量就此降级为种子源）；删空不复活纪律沿用。
- **ScenarioKind → string 别名**：五个 Record 映射同步转数据（SCENARIOS/SCENARIO_HINTS/BRIEF_SPECS/DEFAULT_PLAYBOOK/SCENARIO_ICONS 兜底图标）；内置模板名 == 旧枚举字面量，存量 workspaces.scenario 与 slot_defs.scenarios 字符串级兼容，零数据迁移。
- **消费收口**：buildBrief 与 session 说明书注入改读 state.scenarioTemplates，回落链 = 该场景模板 → 「自定义」基线 → 空块/基线常量（旧备份第二道保险）；briefSpecPredicates 改吃模板集。
- **persist**：PERSIST_TABLES 加 scenario_templates（自然键 ['name']，对齐 M25 教训）；全量 DELETE 手工清单同步；loadLedger 读回（builtin 0/1、JSON 容错）；snapshot 注入。
- **reducer**：`UPSERT_SCENARIO_TEMPLATE {template, previousName?}`（守卫：name 非空/撞名/块 title 非空/kind 表内值/**predicates ⊆ slotDefs（0025 不自开槽）**/内置禁改名/新模板不可自封 builtin——builtin 按库内行裁定）与 `REMOVE_SCENARIO_TEMPLATE {name}`（builtin 拒——回落锚点；被工作区引用拒并列数）。ADD_WORKSPACE 补模板存在校验（CHECK 拆除后的库层替代）。
- **M25 保护解除改级联改写**：UPDATE_SLOT 改名级联加「全部模板 briefSpec 谓词旧名→新名重写」（连 memories/claims 既有级联之后）；REMOVE_SLOT 加「块内剔除谓词、slots 块清空整块撤下 + toast 附撤块数」。自定义模板改名连带级联 workspaces.scenario 与 slot_defs.scenarios（防悬挂引用）。
- **常量退役**：listBriefSpecs 删除（无运行时消费者）。

### UI 层

- Settings 新「场景模板」节：模板列表（builtin 灰 tag、hint 摘要、编辑/删除——builtin 删除禁用）；`ScenarioTemplateDialog` 编辑器（名称 input builtin 禁改、建对象引导、说明书 textarea、简报说明块列表：title + kind 下拉 + slots 块谓词多选勾选、加块/删块；保存带 previousName）。谓词表节场景勾选候选改读 state 模板名。
- **建对象引导差异化**：建对象表单 placeholder = 当前工作区场景模板的 hint（缺模板/空 hint 回落「对象名称」）——补上 scenario.ts:4 注释宣称两年但从未实现的缺口。
- **谓词表 UI 残留保护锁拆除**（Owner 补）：「简报引用」降为提示标记（文案改为说明级联行为），改名/删除不再禁用。
