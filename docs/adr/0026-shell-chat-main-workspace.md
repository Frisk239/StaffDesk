# 主栏是对象上的对话；档案、来源、简报按需右栏；工作区是壳层分组

档案正中的 CRM 三栏会把参谋台做成记录浏览器，对话退成附件。无对象的首页对话会把产品做成知识库问答（0011 已否）。NotebookLM 的对话在笔记本里；Cursor / Z.Code 一类工作台把会话放主栏、工具按需开侧栏。StaffDesk：打开先进入工作区；左侧是该区的对象会话，可收起、可拖宽。点开对象后主栏是该对象上的对话；档案投影、已绑定来源、简报作为右栏标签按需打开，可关、可拖。Inbox 与待确认走图标轨，不是对象页。工作区只是壳层分组，不是账本实体，不能叫「项目」。可新建、切换、移除（须二次确认）；移除后该区对象归档，主张仍按关窗规则留在账本。对象可归档、恢复；永久删除只对已归档且须确认。对话写纪律仍按 0015。投影规则不变：按谓词槽、冲突并排、未知空着、未编目不作定论。形态以 `prototype/` 为准。右栏只读、写入在主栏对话里成交、冲突并排归主栏，见 0027。永久删除对象的级联规则与移除工作区后孤儿对象的找回入口见 0032；工作区建区时选定场景（预设包）见 0033。
