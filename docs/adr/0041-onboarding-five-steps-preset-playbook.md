# 首启向导五步可跳可续；说明书按场景预置默认稿；场景模板可自定义、AI 可提议起草

BYOK + 工作区 + 对象 + 谓词槽的学习曲线全压在首启且零缓冲（审计 B2），而说明书要求「人写」意味着第一次打开读到的是空稿——空说明书是最差状态，指望准备面试的用户先写规矩不现实（同 D6 对谓词表负担的批评）。StaffDesk：首启向导五步——欢迎与选场景（建第一个工作区）、配端点（连通级自检，0039）、资格认证（默认进入可跳过，0039）、建第一个对象（场景引导与建议名称）、指路 Inbox（预填示例不强制真丢）。每步可跳、中途可退：退出即进入正常产品（空工作区 + 未认证徽章 + 左栏低调的「继续设置」入口），不做强制锁——向导铺路不守门，硬门只会把脆弱的 BYOK 首次体验变成挫败。说明书按场景预置默认稿：出站纪律、未知占位、该场景的简报说明默认版，稿头标注「默认稿，可修改」，「人写」修订为「按场景预置、人维护」（与谓词表同构）。场景模板升为可管理对象：内置四个只读，自定义模板四件套齐全（槽表预设、简报说明、建对象引导、默认说明书），可建可改可删；AI 可提议起草新模板——草稿走 takeover 提议（0028 写提议层），模板内引用的新槽逐个按 0025 提议加槽，人确认才入库。
