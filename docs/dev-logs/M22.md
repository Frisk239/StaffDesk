# M22 — relations and the lock-leak hotfix

## Scope

关系刀两段：头班车修 applyResearchRun 锁泄漏（二审发现的唯一 bug 级隐患）并补编排首专测与 eval 闸不变量；本体把 `relationIds` 从死字段变成真边——建边/移边、对象页关系区与跳转、召回关系一跳、对象 note 写入搭车。红线：不动场景/整理/雷达；零 schema 改动。

## Changes

### 头班车（bug 修复 + 测试护栏）

- **锁泄漏修复**（tasks/applyResearchRun.ts）：`runningResearchByObject.set` 连同 TASK_RUN_STARTED dispatch 与 publish 全部挪进 try——修复前 set 与 try 之间的 dispatch 抛错会让该对象永久 busy。finally 按 task.id 守卫释放，has→set 之间保持零 await。
- **live() 全覆盖**：首个 dispatch 前 checkpoint（null→静默让位）；onAudit 内查到哪个实例就写哪个（消除原「查 live 却写旧实例」的半吊子守卫）；APPLY_RESEARCH 前丢弃在途结果的 checkpoint（不写半成品账本）；BIND_CONFIRMED 与抽取循环每轮现取 live brain，executor 循环内构建。恢复备份换 brain 后写入落在当下实例，退出与恢复两条路径都让位。
- **新注入 seam**：deps 加可选 `reach` / `queryFor` / `now`（缺省保持现状），签名向后兼容，调用方零改动。
- **编排首专测**（tests/tasks/applyResearchRun.test.ts，6 条）：正常路径、busy（onBusy 恰一次+返回 null）、**锁泄漏回归钉**（publish 首跳 throw → 第二次调用不走 onBusy 正常收尾）、异常释放、恢复让位（换库后写新库不抛旧连接）。
- **eval 闸不变量**：`STAGE_FLOORED_METRICS` 移入 fingerprint.ts（政策面同家）并导出；fingerprint.test 加「并集无重复且恰等于 QUALITY_METRIC_FLOORS 全集」断言——第 13 个指标将无法静默漏闸。

### 关系本体（设计裁决：裸边无标签、对称双侧存储、仅跨种类三种边）

- actions 加 `ADD_RELATION` / `REMOVE_RELATION` / `SET_OBJECT_NOTE`。
- reducer：ADD 校验五连拒（对象不存在/自指/归档/同种类/重复）中文 TOAST；对称双侧 append；REMOVE 双侧清（关系不做撤销——边可即时重建，注释说明不进 0034 补偿载荷）；SET_OBJECT_NOTE trim 空归 null（loadLedger 对空串读不回）；**DELETE_OBJECT 清对端悬边**（0032 无幽灵同精神）。持久化零改动（M20 脏表路径下 objects 引用一变即同批同步 object_relations）。
- 对象页 Projection 新增关系区（proj-head 与槽区之间）：已关联对象 chips（名称+种类标）点击 `SET_VIEW object` 跳转、chip 移除钮、悬边 id 容错跳过、空态「还没有关系」；「添加关系」面板列兼容种类非归档对象多选确认；note 行内编辑（Enter/失焦提交、Esc 取消、空输入即清空）。右栏档案 tab 经 Projection 复用自动获得。
- **召回一跳**（readonlyTools + session）：导出 `relatedObjectIds`（对称容错读边、跳悬边）；`recallClaims` 本对象优先、一跳补位到总上限 12，一跳条目带 `objectName`；工具描述同步改写。`recallForPrompt` 同一补位逻辑进引用白名单池（否则一跳主张 [ref:] 不可点——session.ts 注释钉住该约束）；prompt 一跳条目前缀「（关联·对象名）」，并新增一行口径提示。未绑定来源仍不进语境（projectionFrom 按对象过滤）。
