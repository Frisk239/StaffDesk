## 返修记录（2026-08-29 独立验收后）

1. **托盘退出真 bug 修复**：`quitting` 标志原先只在托盘菜单置位，任何外部 `app.quit()`（系统退出、程序化退出、E2E）都会被 `close` 处理器 `preventDefault` 拦成隐藏窗口，进程永不退出。修复：`tray.ts` 导出 `markQuitting()`，`index.ts` 的 `before-quit` 里先置标志再清理——Electron 官方 tray-quit 模式。E2E 从超时变 10.1s 通过。
2. **e2e/persist.spec.ts 适配两个语义**：全新库必弹首启向导（先点「跳过向导」再操作）；`close()` 在托盘语义下不退出（改走 `app.quit()`）；断言改 `.first()`（对象名在会话轨/顶栏/投影多处出现，strict mode 拒绝歧义定位）。
3. **CI 补 ABI 对齐**：单测经 `ELECTRON_RUN_AS_NODE` 跑在 Electron 运行时，`npm ci` 只带 Node ABI prebuilt，CI 的 test 前加 `npm run rebuild`。GitHub Actions run 33232192598 全绿（14 文件 47 测试、覆盖 88.01%）。
4. **安装包冒烟**：`dist/win-unpacked/StaffDesk.exe` + 全新 `STAFFDESK_BRAIN` 数据目录，跳过向导→建区→建对象→`app.quit()`→重启断言对象仍在——四项全绿（截图 `.playwright-cli/pkg-0*.png`）。
