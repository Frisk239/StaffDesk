# M20 — dirty-table persistence writes

## Scope

拆性能墙：`Brain.dispatch` 的持久化从「每次全量 DELETE-all/INSERT-all 14 表 + 事务外 FTS 全量重建」改为按脏表差异写入，全量重写保留为修复与等价性对照通道。先落 ADR 0056 再写代码。红线：不新增任何账本功能面；读路径（每 dispatch 两次 loadLedger）本刀不动，留后续刀。原计划并入本刀的 eval 升级、编排合一、脱敏收口拆出为 M21。

## Changes

- ADR 0056 落裁决：判脏 = 集合引用变化（fast-path）+ 行级主键三分自愈（库有 next 无 DELETE / next 有库无 INSERT / 两侧都有且除 created_at 外行值不等 UPDATE）；UPDATE 保留 created_at（语义从「最后重写时间」变「首次落库时间」）；operations/certs/scenario_brief_specs 与 app_meta 非清单键不在 diff 射程；FTS 仅 claims 脏时重建并移入事务；写路径单漏斗与 reducer 不可变性升格为红线。
- `persist.ts`：原 persistLedger 内 14 表的行构造逐段提取为 `PERSIST_TABLES` 规格表（table/columns/primaryKey/collection/rows），全量与 diff 共用同一份行构造，防两路漂移；新增 `persistLedgerDiff(db, prev, next)`——引用相同整表跳过，不等才 SELECT 库内现行做主键三分；presets 种子的旧格式槽 id 与迁移外直写行在首次触达时自然收敛。
- `brain/index.ts`：`Brain`/`openBrain` 增加可选 `persistMode`（默认 `diff`，`full` 为修复/对照通道），dispatch 按模式选路。
- 新增 `tests/brain/persist-diff.test.ts`（验收核心）：冻结时钟 + mock 随机源，两颗 Brain（full/diff）灌约 80 条 dispatch 的同一剧本（绑定→抽取→晋升→纠正→撤销、批量晋升/回退、槽表触达、任务审计幂等与手动停止、雷达迟跑、ingest、模型设置），断言 loadLedger 深相等、operations 序列相等、FTS 语义相等（含「跳过重建≠漏重建」反证）、**纯 UI 动作在 diff 路径下 15 表写语句数为零**、关-开两轮后仍相等。
