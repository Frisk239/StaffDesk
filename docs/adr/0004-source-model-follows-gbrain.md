# 来源模型参考 GBrain：渠道、未核、本人优先；派生不是来源

把「手给 / 调研 / 派生」打成一个真值排行会混进料路径、材料角色和派生关系。GBrain 把渠道类型（用于引用）、受信任写入 vs 自动抽取隔离、冲突优先级分开：本人陈述最高，网页搜索不能盖过本人；自动抽取默认未核，晋升前不进入出站定论的召回。W3C PROV 里派生是关系不是来源。StaffDesk 采用同一结构，不照搬 GBrain 的会议/融资 API 等渠道清单：进料路径为手给或调研；调研默认未核；材料角色为主键或转述；派生句必须指回已有主张。冲突两侧保留。未核调研不得盖手给、不得当简报单边定论。同级互斥仍摊开。不引入 Admiralty 六档或域名权重。
