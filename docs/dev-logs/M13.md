# M13 — Electron 运行时安全边界

## 本批完成

- 新增 ADR 0047：把主窗口沙箱、导航、新窗口、外链、权限请求、webview 与 IPC sender 校验收束成
  StaffDesk 的 Electron runtime security boundary。
- 主窗口启用 `sandbox: true`，并显式保持 `contextIsolation: true`、`nodeIntegration: false`、
  `webSecurity: true`、`allowRunningInsecureContent: false`。
- 新增 `app/src/main/runtimeSecurity.ts`：集中维护 StaffDesk 页面判定、外链协议 allowlist、窗口跳转处理、
  webview/权限拒绝和 IPC sender 校验。
- `setWindowOpenHandler` 与 `will-navigate` 现在默认拒绝在应用内跳转；只有 `http:` / `https:` 会交给系统浏览器，
  `file:` / `javascript:` / `data:` 等危险协议不会进入 `shell.openExternal`。
- 所有 `ipcMain.handle` 经 `handleTrusted` 包装，只有主窗口的可信 StaffDesk frame 能调用读写大脑、密钥、
  文件选择、导出、调研、模型认证等 privileged IPC。
- preload 打包为 sandbox 可用的 CommonJS 入口，`window.staffdesk` API 名称与 renderer 调用不变。
