# M5 出站与撤销

状态：自测完成。

## 做了什么

- 出简报必须过出站闸：没有主张 ID 的句子改成未知占位；伪造 ID 丢掉；未编目不得当单边定论。有 Key 时模型可按场景块组句，仍过同一道闸。
- 出简报任务结束仍弹出「全部晋升 / 全部保持」（唯一批量白名单）。
- 抽取后若有滞留未核，待确认里会出现「丢弃未核」提议。
- 撤销是补偿写，进操作日志（`undo_of`）。关掉应用再开，结果卡上仍能撤晋升。永久删除对象不给一键撤销。
- 操作日志里的密钥会被抹掉。

## 怎么点

对象顶栏「出简报」→ 右栏简报每句能点回主张。纠正未核=丢掉；纠正已晋升=关窗+禁写。结果卡「撤销」可撤回晋升/绑定等。
