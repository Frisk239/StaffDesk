# M18 — design decisions: ADR 0052–0055

## Scope

四条悬置的设计决策（prototype-refit 待拍板 §1/§4/§9/§11）拍板落 ADR。本刀只落决策与文档同步，不写实现代码；实现按依赖排进后续里程碑。

## Decisions

- 0052 对象身份：对象只由人确认建立，整理可提议「发现疑似新对象」，抽取与调研不自动建；v1 不做别名。解锁关系系统的设计。
- 0053 冲突互斥：单值槽上归一化取值不同（大小写/空白/全半角）即冲突，多值槽永不自动冲突，模型不得判互斥；「其实是同一个值」走合并重复主张提议。解锁冲突判定系统化与整理「标可能过时」。
- 0054 禁写粒度：禁写存（对象、谓词槽、归一化取值）+ 被纠正原句，双路拦截作用于出站闸与提议生成；抽取入账不拦。「纠正复发」指标由此获得可测定义。解锁记忆/dream 实质化与金标升级。
- 0055 记忆范围：提议按内容给默认 scope，确认卡上可改，dream 不改已确认范围。解锁记忆管理 UI。
