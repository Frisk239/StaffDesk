# 滞留未核按入库满 N 天才提议丢弃；接受按 live 重算

0037 规定整理可对「滞留多日的未核」提议丢弃，人确认才删。实现却把该对象当前全部成立且未核装进丢弃卡，抽取当下就能一键清掉刚抽出的主张；晋升只翻未核标志，接受仍按 payload ID 删行，已核主张也会被删。拍板：滞留是**这条主张**的属性，不是对象的——入库满 N 天、仍成立、仍未核才算；时钟用入库时间，不用有效期；打开档案、提问、给同对象抽新材料都不清零。N 默认 7 天，设置页可改，范围 1–90（0 禁止，避免 P1 回流）；这份偏好**跟机器走**，进 `userData`，不进 `brain.db`，备份不带走（0048），换机器回到 7。晋升 / 纠正 / 关窗 / 删除后，挂起的丢弃卡当场按 live 滞留集合刷新，一个不剩才撤。接受时再按 live 重算，只丢此刻仍滞留的，并把实际作用清单给用户看；改 N 同一套刷新。抽取钩子仍跑（刚抽出的进不了卡）；打开「待确认」时按当前 N 扫描生成或刷新。驳回后滞留集合不变就不再出卡，集合变了才出新卡；任务结束的批量卡仍是 0037 的另一出口。
