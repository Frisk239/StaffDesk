# M25 — slot table editing with cascade discipline

## Scope

补齐受控谓词表的管理面：UPDATE_SLOT（改名 / 单值↔多值 / 场景适用标记）与 REMOVE_SLOT（删除），级联纪律先落 ADR 0057。红线：不动 UndoPayload（不进撤销卡）、不动 schema 版本（app_meta 键零迁移）、BRIEF_SPECS 引用的内置谓词受保护（M26 场景数据化前）。

## Changes

- **ADR 0057**：编辑是人手设置动作直接改账本、operations 留痕；改名级联三处（槽表 / 该槽主张 predicate / 禁写结构化 bannedPredicate——不同步则禁写静默失效）+ 撤指向旧名的挂起提议；删除把成立主张降为「未编目」（自动获得 0037 全套降级语义）、已关窗保留旧名作历史；守卫（空名/保留值/撞 UNIQUE/BRIEF_SPECS 保护/kind 不可改）；多值→单值告知将派生的冲突处数（0029 派生，人消解）；种子门改首启标记防复活。
- **reducer**：UPDATE_SLOT / REMOVE_SLOT 两分支（注释挂 0057）；辅助 `claimBelongsToSlotKind`（按对象种类分区收窄级联，同名槽跨分区不误伤）、`withdrawTidyProposalsAbout`（挂起提议置 reject 留审计痕迹）。
- **种子防复活**：seedPresets 门从「表空才插」改为 app_meta `presets_seeded` 首启标记；既有库（表非空无标记）只补标记不重播；scenario_brief_specs 同扇门。
- **persist 偏离（测试逼出）**：slot_defs 的 diff 主键从位置制 `['id']` 改为自然键 `['name','kind']`——REMOVE 使数组移位时按 id 三分会产生瞬时 UNIQUE 冲突；改自然键后删槽=删行、改名=换行，0056 等价性由 persist-diff 三用例继续背书。
- **UI**：SlotTable 行内铅笔编辑（SlotEditDialog：槽名 input 受保护禁用、单值/多值切换、bind-panel 式场景勾选含显式「通用」）+ 删除确认（SlotDeleteDialog 照 SourceDeleteDialog：预计算「成立主张 N 条将降未编目、涉及对象 M 个」+ danger 确认）；受保护槽带「简报引用」tag、删除禁用。
- scenario.ts 导出 `briefSpecPredicates()`（守卫查常量不查死副本表）。
