# M15 — 任务运行控制与回放可操作化

## 交付

- 调研 / 再搜一轮启动时先写入 `进行中` 任务，用户在对象页顶栏能立即看到“调研中”与当前预算档。
- 调研过程中的体检、搜索、打开、失败、触顶、停止等步骤会增量写入 `task_audit`，任务回放页可在运行中或结束后打开查看。
- 对象页和回放页新增“停止”入口；用户主动停止落为 `已停止 · 手动`，不新增“取消”状态。
- 主进程 IPC 对同一对象运行中的调研加本机运行闸，避免停止收口期间重复启动第二轮。
- 回放页从旧的简陋来源卡改为任务时间线，返回时回到对应对象页。

## 架构记录

- 新增 ADR 0049：任务运行控制先落账；停止是运行时信号，回放读任务审计。
- 未改数据库 schema；继续复用 `tasks` 与 `task_audit`。
- 不触碰模型配置、API Key、资格认证或备份恢复边界。

## 已知限制

- 当前 Reach 适配层尚未把 `AbortSignal` 下推到外部 CLI / fetch；停止请求会在当前工具调用返回后立即收口，不会继续下一步，也不会伪造来源。
- M15 只做对象页任务控制与回放，不做全局任务中心。
