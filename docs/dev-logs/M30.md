# M30 — multi-path research: fan-out over zero-config paths (ADR 0061)

## Scope

「检索」词条「多路并行」兑现（ADR 0061，G3 实现刀）：reach 从单后端抽象为路径清单，Exa + GitHub 公开搜索两路起步，引擎并行扇出 + URL 去重合并，searches 硬顶按路计，审计记路径与各路成败。本刀恢复 Owner 直接派发模式，并重申探索者先行（开刀时跳步被用户纠正，探索报告改了三处施工单：GitHub 路定匿名 REST——本机 mcporter github 凭据坏且枚举 17.6s；扇出与去重放 engine；失败路也计入 searches）。

## Changes

- **adapter 路径清单（reach.ts）**：ReachAdapter 升级为 `paths: ReachPath[]`（name/doctorCheck/search）+ 聚合 doctor（逐路红绿、红路不挡绿路、全红才给安装引导）+ 不分路的 open（Jina Reader 原样）。Exa 路 mcporter 调用逐字搬入；GitHub 路 = api.github.com 匿名 REST（search/repositories?per_page=5，复用注入 fetchFn；403/429 →「匿名额度用尽」、非 200/网络错/非 JSON 抛带因错误、缺 html_url 条目丢弃不编造；体检恒绿避免白烧限速，真失败搜索时按路审计）。e2e 罐头双路（GitHub 含 Exa 同 URL 镜像命中验证去重），`STAFFDESK_E2E_REACH_FAIL` 两路对称注入（评审整改：原只 GitHub 路认）。
- **引擎扇出与预算（engine.ts）**：体检绿路 Promise.allSettled 并行扇出（同步抛错折 rejected）→ mergeSearchHits 纯函数按 URL 全局去重（同 URL 留先到、计 duplicates，export 供单测）→ 打开入库。searches += 参加扇出的路数（失败路也计，防坏路重试烧墙钟；0059/0061 注释在案）；体检结论与路清单对不上时失败收口不静默空跑（0008）。
- **审计与回放**：「搜索」行记扇出路名（发起了什么）；「搜索结果」payload 含每路 {name, ok, count, error} + 合并 count/duplicates；每条失败路单独记「搜索失败」（加 path 字段）；全路失败 stopReason=失败、保持未知不编造（0008/0030）。ReplayView 对带 paths 的行人读渲染（「Exa ✓ 2 条 · GitHub × 限速…」），解析失败退回 JSON。
- **ADR 0061 落地补记**：「每路 =（mcporter 工具名…）」修正为「本机零配置查询通道」——GitHub 路 mcporter 被勘察否决，改匿名 REST 直连；gh 认证只算本机红利不进产品路径。
