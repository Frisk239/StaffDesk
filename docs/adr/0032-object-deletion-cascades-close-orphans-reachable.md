# 永久删除对象级联关窗（对象误建）；移除工作区产生的孤儿对象有找回入口

「永久删除只作用于已归档对象」说了删除的前提，没说主张、简报、会话的去向：挂空 objectId 的幽灵主张会断审计链，级联删主张又违反账本保守哲学。工作区移除路径同样有洞：区内对象被归档但 workspaceId 悬空，于是在任何工作区都不可见、主张还在账本里（refit §6 挂起项）。StaffDesk：永久删除已归档对象时，其名下全部主张级联关窗，关闭原因「对象误建」——待遇同「从未成立」，不再出站、保留防再写入；简报保留为孤儿快照（出站历史不回改，简报卡片上标注对象已删）；会话随对象删除。移除工作区后悬空的归档对象不是丢了，是没入口：图标轨给「全部对象」列表（含已归档、含无工作区），可查看、可恢复进任一现有工作区，恢复后主张投影照常（账本从不因壳层分组而丢失）。移除工作区的确认弹窗必须写明这一后果。两级删除语义对齐：删工作区动的是可见性（对象归档、可找回），删对象动的才是账本（主张关窗、不可逆）。
