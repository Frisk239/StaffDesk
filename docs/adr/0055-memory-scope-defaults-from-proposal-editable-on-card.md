# 记忆范围由提议给默认，确认卡上可改

候选记忆的 scope（全局/对象/会话）此前由提议生成时的 payload 给定，确认卡上不可改；默认判错时使用者只能整条拒绝，等下一轮重新提议，没有纠错口。

抽取循环按记忆内容给默认范围：关于当前对象的使用习惯给「对象」，明显跨对象的偏好与禁写给「全局」，只关本会话的给「会话」。确认卡上提供范围选择，确认时以人选为准，未改动则用默认。范围仍是记忆自身的属性，不产生新账本结构；dream 整理不得改写已确认的范围。

prototype-refit 待拍板 §11 由此裁决；确认卡保持 0028 的 takeover 语义，改范围不等于绕过确认。
