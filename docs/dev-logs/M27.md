## Changes

### 审计修复（F1-F5 + G9，代理 A）

- **F1 删除模板级联**：`REMOVE_SCENARIO_TEMPLATE` 清理 slot_defs.scenarios 残留引用（0058 ADR 补记删除级联口径）。
- **F2 确认写守卫与队列级联**：CONFIRM_WRITE 回退分支补 `slotIsControlled`（经 claimBelongsToSlotKind 种类感知，不再误吃异种同名额）；UPDATE_SLOT / REMOVE_SLOT 级联改写/撤下挂起的 write_queue 整理行（renameTidyWriteQueue / dropTidyWriteQueue）。
- **F3 嵌套弹层 Esc 双关**：审计建议的 stopImmediatePropagation 方向反了（外层先注册先触发）；实际修复 = useMiniDialogEscape 以 capture 相 + stopPropagation 让内层先吃 Esc，外层不再连坐。
- **F4 持久化覆盖**：persist-diff 剧本补 scenario_templates 行为与新动作（模板 CRUD + 槽动作交叉），0056 等价性维持。
- **F5 e2e 隔离**：5 处启动全部走独立 user-data-dir，规格不再依赖开发机真实模型配置。
- **G9 版本守护**：floored 指标与 stage 映射、政策版本正向覆盖的守护测试（eval 集合改后必须复跑从自觉变有闸）。

### 打磨（代理 B）

- **资格收口**：向导检查步进入即自动起跑资格检查（「稍后检查」= 0041 可跳过口径；autoCheckFired / checkSkipped refs 防重）；「未认证」徽章进顶栏 topbar-ctx——未配置不显示、配置后常驻、点击直达设置模型节（Settings initialSection 最小扩展）。
- **任务列表**：状态（全部/进行中/已完成/已停止）与种类（调研/再搜一轮/出简报/周期性雷达）筛选、进行中置顶、雷达行显示下次时间、失败/已停止行「再搜一轮」带上轮语境。

### 词条（Owner）

- **G8**：「候选记忆」由「会话结束才产」改为「逐轮即产、随会话累积，不等会话结束」——实现本就每轮抽（更优），词条对齐并消除与 ADR 0022 的漂移。
