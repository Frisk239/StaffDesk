# 主键标记是绑定级角色：域名启发建议、整理卡提议新版过时、转述永不自动过时主键

「主键」词条整块未兑现（审计 G1）：SourceRole 类型与展示 tag 存在，但无任何 action/UI 能设置。拍板最小闭环三轴：**标记粒度 = 绑定级**——角色存在 (sourceId, objectId) 绑定上而非来源上，同一 URL 对对象 A 是官网（主键）、对对象 B 是媒体报道（转述），冲突展示与简报标注按当前对象视角取角色；**系统可建议 = 域名启发建议卡**——对象带官网/主页字段时，来源域名与之一致则在绑定时出「建议标为主键？」确认卡，人点才生效，启发式永不自动定（词条口径）；**新版过时旧版 = 提议整理卡**——冲突派生（0029）时若双方主张均出自主键绑定且来源时间可辨（新 v 旧），自动提议「旧版过时？」整理卡，人确认才关窗、关闭原因「被主键新版取代」，不消解冲突（对齐「晋升不消解冲突」）。不变量：任何自动路径都不得因转述来源关窗主键主张（当前系统本无自动关窗，此条立为守护测试，防未来回归）。建议卡与整理卡都是提议，不是写账本动作；确认走既有 takeover/整理通道，operations 留痕可撤销（0034）。M29 实现。
