## Deviations / Notes

- 执行者四处偏差（评审判正当）：showErrorBox+exit(1) 实测不等用户、损坏库 e2e 断言盘上证据而非点原生框、logs:export 自证一行、句柄泄漏修复（勘察外）。
- CI 安装落点硬编码 `Programs\StaffDesk\StaffDesk.exe` 依赖 productName 不变（记档）。
- **CI 事故与修复（PR #29 首跑，两独立问题）**：① check job——vitest（跑在 Electron-as-node）文件级并行时多 worker 竞争 vite-node 的 /tmp ssr 模块缓存，Electron 补丁过的 fs 加剧竞态，整片 ENOENT unhandled 把 run 拱红（首个运行**零断言失败**仍 exit 1；第二个运行附带一个 disk I/O error 连带伤亡）。判别实验：M32 绿色运行在当前 runner 重跑仍绿=非 runner 漂移、M33 触发。修复：vitest `fileParallelism: false` 串行化消除跨 worker 缓存竞争（本地全绿覆盖率不变）。② e2e job——损坏库 spec 双 60s 超时：CI 无人会话上 showErrorBox 阻塞主线程等人点框（本地有桌面实测立即返回，故本地绿）。修复：`STAFFDESK_E2E_SUPPRESS_ERROR_BOX=1` 环境变量抑制原生框（e2e 走日志+盘上证据链），真实用户不受影响。
