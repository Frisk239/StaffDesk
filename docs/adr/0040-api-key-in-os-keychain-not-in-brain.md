# API 密钥进系统密钥库，不进大脑文件

BYOK 客户端常见做法是密钥存配置库里明文字段（Cherry Studio 一类），省一层抽象。StaffDesk 不这么做的决定性理由是产品性的：大脑文件（SQLite 单文件，0020）将来是可导出、可备份、可跨机迁移的，密钥若躺在里面，每次导出都要做「先把密钥抠出去」的手术，忘了就是事故；密钥在系统密钥库（Electron safeStorage：Windows 凭据管理器 / macOS 钥匙串），大脑文件天然就是不含密钥的干净快照——导出零处理，迁移到新机器重填一次密钥即可。副作用可接受：SQLite 备份单独恢复时密钥仍在原机密钥库里，无缝衔接。密钥不进操作日志（0035 已定）；设置页密钥框掩码显示。密钥的修改属 0028 的不可逆类操作，不给模型工具。
