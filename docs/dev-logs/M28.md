# M28 — read-path debt knife + fee dimension

## Scope

审计排定的读路径债刀四件 + 滑落的费用维度（G4）：双 loadLedger 对齐 0051、syncTable 增量化、taskAudits 主键/索引/保留（schema v10）、FTS 触发器接线；费用维度按 ADR 0059 落地（usage token 计量、档位预算、费用触顶、hops 死维度删除）。用户裁决（2026-09-01）：计费口径 = usage token 数；费用维度捎带本刀。红线：不折金额不建单价表、跳链只删声明、chat 不进任务预算。

## Changes

### 读路径债（代理 D）

- **双 loadLedger 对齐 0051**：dispatch 单次 loadLedger 构造 prev，persist 后直接返回 next（刚写入的即库态）；listDeletedSourceRecoveries 移出 snapshot——开库扫一次缓存，仅 DELETE_SOURCE / RESTORE_DELETED_SOURCE 后重扫；trackLedgerReads seam 断言单次 dispatch 读数为 1。
- **syncTable 增量化**：全列 SELECT 只按内存主键集（json_each 展开 IN）；主键列判多余行（无多余不发 DELETE，保住纯 UI 动作零写）。引用 fast-path 未动；0056 冻结时钟等价套件全绿；新断言全列读取行数 ≤ wanted。
- **task_audits v10**：PK (task_id, seq) + task_id 索引；撞键合并规则（同键留 ts 最新，ts 同值留更大 rowid）进迁移测试；pruneTaskAudits 纯函数——每任务 500 上限裁 (ts, seq) 最旧，kind ∈ {触顶, 费用触顶, 手动停止, 失败} 豁免（引擎「停止」行 reason 映射同判）；dispatch 在 taskAudits 引用变化时先裁再落库。
- **FTS 触发器**：核实 TEXT 主键 UPDATE 保 rowid 后挂 claims 三触发器（INSERT/UPDATE/DELETE）维护 claims_fts；rebuildFts 保留为 0056 全量修复通道（与触发器终态幂等，不 DROP 触发器）；新测试直 UPDATE claims 后 FTS 立即反映。
- **tasks stop_reason CHECK**：同一 v10 门重建加「费用触顶」（SCHEMA_SQL/门次/迁移测试三处同步）。

### 费用维度（代理 F，ADR 0059）

- **usage 链路**：chatCompletions 从非流式 JSON 与流式末包解析 usage.prompt/completion_tokens（缺失或非正数 = 未回传，不静默当 0）；applyResearchRun 只包装调研/再搜一轮/雷达的抽取 complete——每源记 kind「费用」累计行（prompt/completion/total/missingUsageCalls），缺失则 missingUsageCalls+1 并标注「端点未回传 usage」。用户手发 chat 不进任务预算；再搜一轮新任务新预算；雷达每周期独立子任务独立预算。
- **预算与触顶**：Budget 加 tokens（快搜 120_000 / 深挖 400_000，按打开上限 × 单片段抽取估算）与 missingUsageCalls（8/20，按搜索次数对齐）；删 hops（引擎无跳链行为，声明未执法属谎言口径——Budget/测试/UI 引用全清，留反断言测试）。费用维先于搜索/打开/步数/墙钟判定；触顶走 TaskStopReason「费用触顶」，已打开照写、未抽的保持未知（「硬顶」词条纪律）。
- **显示**：任务行显示该任务最新累计 token（formatTokenCount，`12.3k token`）；回放渲染费用行（累计/输入/输出）与「端点未回传 usage」标注。
- **纯函数**：app/src/shared/taskFee.ts（recordFeeSpend 累计/缺失退化、feeAuditPayload、latestTaskTokenTotal）。
