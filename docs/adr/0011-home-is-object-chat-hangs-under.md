# 首页是对象；对话挂在对象下，不是无对象的聊天框

把主界面做成全局对话，档案和主张会退成后台表，产品会重新变成知识库问答。NotebookLM 的对话在笔记本里、受该本来源约束，笔记本之间隔离。Salesforce Chatter、工单评论都挂在记录上，全局 feed 只是旁路。ChatGPT 式首页对话是另一类产品。GBrain 的家是人/公司页，不是聊天框。StaffDesk：打开先看到人/组织/项目列表与对象页。主张账本是抽屉。Inbox 只负责丢来源，不负责闲聊。跨对象办事走任务，任务从某个对象点进去。对话挂在当前对象下，默认语境是该对象的来源与主张；点到关联对象可以拉进这次对话。不存在「不属于任何对象」的首页会话。
