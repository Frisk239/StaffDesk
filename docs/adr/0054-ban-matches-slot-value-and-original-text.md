# 禁写按「槽+归一化取值」与原句双路拦截

0006 定了纠正必须写禁写，否则同样错误会再出站。此前实现是禁写记忆文本对主张正文的精确子串匹配：模型把句子改写一版就漏，「纠正复发」指标（0010/0045）因此没有可实现的判定。

禁写记忆结构化为双路：一路存被纠正主张的（对象、谓词槽、归一化取值），一路存被纠正原句。出站闸与提议生成两处按任一路命中即拦：同对象同槽同归一化取值直接拦（拦住换措辞复述与再抽取的同一结论），原句精确命中也拦。抽取入账不拦——被纠正命题仍可作为未核主张进账本，禁写管的是出站定论资格，与「未核可进账本」的口径一致。

「纠正复发」由此获得可测定义：金标里重放被纠正主张（再抽取、再生成简报），断言两处闸口均未放行其作为单边定论。语义级禁写（模型判句义相近）明确不做：出站闸保持确定性。

prototype-refit 待拍板 §4 由此裁决。
