# 冲突互斥按单值槽归一化取值判定，不做语义判断

0029 定了冲突是派生关系：同对象、同单值谓词槽、有效期重叠、取值互斥。但「取值互斥」由谁判一直没有裁决：文本不等过于机械（空白差异也算互斥），语义判断又非确定、与派生口径冲突。

互斥判定收敛为纯规则：单值槽上、双方未关窗、有效期重叠、归一化取值不同即冲突；多值槽上的并存永不自动建冲突。归一化只做大小写、空白与全半角，不做同义改写——「北京」与「北京市」仍判冲突，由人按 0029 的唯一路径关窗或纠正消解，系统不裁决谁对。

判定因此确定、可单测、可进金标（冲突检出指标按此口径复跑）。模型不得产出冲突判断；若整理时发现两条主张「其实是同一个值」，走合并重复主张的提议，不走冲突消解。
