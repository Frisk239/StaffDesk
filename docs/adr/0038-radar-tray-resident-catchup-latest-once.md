# 雷达托盘常驻按时跑；彻底退出期间只补跑最新一次，迟跑与未跑如实标记

refit §7 挂了三轮「应用没开时雷达怎么算」：纯补跑牺牲按时性，后台进程又违背桌面形态直觉。用户拍板走桌面惯例：点叉只是收进系统托盘（首次点叉 toast 提示一次「已最小化到托盘，右键托盘图标可彻底退出」），托盘单击唤起，托盘右键菜单才是彻底退出。常驻期间雷达按时跑；彻底退出、系统重启、崩溃、休眠期间错过的周期，下次打开只补跑最新一次——跳过的周期在回放里如实记「未跑」，补跑的轮次带「迟跑」徽章，诚实记录优先于假装完整；只补一次也守住 BYOK 的成本纪律（打开应用不烧一串钱）。雷达完成默认不发系统通知（应用内徽标 + 下次打开时摘要横幅），设置可开。托盘只是窗口形态，0023 主进程拥有大脑与循环的裁决不变。
