## Changes

- **词条（P-A/P-C）**：快搜硬顶列表删「跳数」（与 0059/实现/进度条目的三重矛盾收口）；检索词条「向外搜、打开、跟踪链接的动作」→「向外搜与打开的动作」（引擎无跳链）。
- **简报主键标注（P-B，0062）**：BriefSentence 加独立可选字段 `primarySourceIds`（**不进 flag 联合**——briefOut sanitize 会重写 flag）；buildBrief 经共享纯函数 `primarySourceIdsOf`（内部 isPrimaryBacked → bindingRole，按当前对象视角）填主张/综合/未编目句；briefGen LLM 分支按 claimIds 同函数回填（有模型时标注不丢）；出站闸未编目降级路径显式保留字段。BriefView 渲染「主键来源」tag（复用现有样式）。
- **fetch 超时（D1）**：reach 两处 fetchFn 挂 `AbortSignal.timeout`（search 25s / open 20s 对齐 spawn 口径，注释挂审计 D1；TimeoutError/AbortError 双接：search 折 ReachError、open 折 ok:false）；**engine 墙钟 race 兜底**——搜索扇出与单次打开各以墙钟剩余为等待上限折「搜索/打开超时」（罐头挂起注入不走真实 fetch，引擎侧是唯一可测路径；正常时序不受影响——快搜 3min/深挖 15min 墙钟 ≫ 25s/20s）；`STAFFDESK_E2E_REACH_HANG`（'search'|'open'）+ `STAFFDESK_E2E_WALL_MS` 注入（对齐 TOKEN_BUDGET 家族）。
- **简报出站出口（F4）**：shared/briefMarkdown.ts 一份组装（句后 [^n] 脚注 + 文末列谓词/来源定位/片段）；「复制 Markdown」与「导出 .md」共用；导出走 brief:export（照 brain:export 的 showSaveDialog 模式）。
- **unparsed 重导（F8）**：占位卡「重新获取」表单，预填从 origin.locator 或标题/正文提首个 http(s) URL（存量 origin_json v3 前不回填，提不出手粘）；走既有 ingestUrl；「删除占位」走既有 SourceDeleteDialog 级联不自动删。
