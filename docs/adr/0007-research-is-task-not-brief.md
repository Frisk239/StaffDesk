# 调研由任务触发；简报读账本，不自动重搜

每次打开 Brief 都现场搜会把费用、腐化和未核材料冲进定论；常驻爬虫是另一款监控产品。业内 Deep Research（OpenAI、Gemini、NotebookLM）都是使用者显式开一轮、可在后台跑完再入库，问答默认仍受已有来源约束。GBrain 是 brain-first：先查大脑，外部 API 只补缺口；enrichment 按任务/档位花钱，不是每问必搜。StaffDesk：调研从属于任务（面试准备、主张核查、再搜一轮），过程可看可停可回放。生成简报只用当时账本：已晋升当定论，未核带标记，没有材料则未知。周期性雷达若做，也是带边界的任务，不是隐式后台。获取实现参考 Agent Reach（多平台路由、体检、失败重试），写入纪律仍走本仓库的来源分级、未核与主张对齐。
