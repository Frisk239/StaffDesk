## 做了什么

- 绑定确认后走 `extract:run`：有 Key 时用结构化 JSON 抽主张；没有 Key 时退回 M1 桩。
- 0024：谓词必须落在受控槽，对不上记未编目；span 必须能在原文里找到，否则丢掉；幂等键 = (来源, 对象, 谓词, 片段)，重跑不追加。默认未核。
