# 召回按关键词加关系跳对象即为 v1 口径；向量明确出范围

「召回」词条原写「默认关键词加向量」，ADR 0042 只是暂缓从未改判——承诺悬空至今（审计 G2）。拍板：改判词条，v1 召回 = trigram FTS 关键词（0004 的中文三字切片与短查回退）+ 关系一跳（M22：关联对象的已绑主张进召回池与引用白名单），向量明确不在 v1 范围。理由：BYOK 本地应用，向量路径要 embedding 调用（花 token、断网即废、费用维度刚按 0059 立起来又要管 embedding 开销）+ 向量存储 + 混合排序三件套；个人参谋台的小语料下关键词 + 关系跳对象已覆盖「找全、找对」的主场景。未来若语料规模或漏召率真的顶到关键词天花板，再带实测数据重开此 ADR，不在承诺里留活口。
