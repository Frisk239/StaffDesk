# M12 — Electron 安全升级与原生 SQLite 验收

## 本批完成

- 新增 ADR 0046：Electron 安全版本线升到 44；SQLite 绑定改走 `better-sqlite3` 13 的 N-API
  预构建包，常规验收使用 Electron 原生加载烟测，不再要求每台 Windows 开发机都有 C++ 编译工具链。
- 将 `electron` 升到 `^44.0.0`，`electron-builder` 写实到 `^26.15.3`，`@electron/rebuild`
  写实到 `^4.2.0`，`better-sqlite3` 升到 `^13.0.3`。
- 新增 `app/scripts/verify-native-sqlite.mjs`，通过 Electron 的 `ELECTRON_RUN_AS_NODE` 加载
  `better-sqlite3` 并写读内存 SQLite，确认发布运行时可以使用本地大脑。
- `npm run native:check` 成为 CI 的原生绑定门禁；`npm run rebuild` 保留为兼容入口并委托到
  native check，`npm run rebuild:force` 保留给有 C++ 工具链时的源码重编。
- electron-builder 关闭 `npmRebuild`，避免打包时强制源码编译；发布包继续通过 `asarUnpack`
  携带 `better-sqlite3` 的预构建 `.node` 文件。
- M11 -> M12 intake 已记录：M11 合并通过，M12 入口债务为 Electron / extract-zip high advisory。

## 已知边界

- 本批只消除当前 Electron / extract-zip 安全债，不改变 BrowserWindow sandbox、外链 allowlist、
  权限策略或 renderer 架构；这些安全硬化需另开 ADR 与产品验收路径。
- `app/dist/` 与 `app/out/` 是本地构建产物，已由 `.gitignore` 忽略，不随提交进入仓库。
